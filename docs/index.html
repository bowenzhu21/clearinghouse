04 / Transaction boundary

One local commit, then retryable delivery

Strict JSON event→Idempotency check→Event + journal + outbox→Leased worker→Consumer inbox

The event, balanced journal, idempotency response, and outbox message share one SQLite transaction. Delivery is at least once; a consumer receipt transaction makes retries safe for the demonstrated side effect. SQLite has one writer. This is a single-host reference implementation.
